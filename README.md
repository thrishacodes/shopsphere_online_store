# Shop Sphere - Online Store

   A full-featured responsive E-Commerce web application built with HTML5, Tailwind CSS, and JavaScript.

   ## Key Features
   - *Product Catalog:* Filter by category (Electronics, Fashion, Home, Accessories), price range, and global text search.
   - *Cart & Checkout:* Slide-out drawer, quantity modifications, subtotal + 8% tax calculator, and mock checkout modal.
   - *Order Tracking:* Unique Order ID generation (ORD-XXXXXX) and live status tracking progress bar.
   - *Role-Based Access (Admin/User):* Toggle roles directly to access the Admin Panel (Total revenue, order stats, product CRUD operations, and order status updates).
   - *Persistence:* All data persists locally via localStorage.

   ## How to Run
   Simply open index.html in any web browser!
